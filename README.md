# Student Task Tracker

A simple Python application to manage daily tasks using **Object-Oriented Programming (OOP)**. Users can **add, view, update, and delete tasks**, which are stored in a JSON file.

---

## Features

- Add new tasks with a title and description.
- View all tasks with their creation time.
- Update task title or description.
- Delete tasks with confirmation.
- Tasks are stored in a JSON file (`tasks.json`) and loaded automatically when the program starts.
- User-friendly task numbering for easy updates and deletions.

---

## Technologies Used

- Python 3
- OOP (Classes: `Task` and `TaskManager`)
- JSON for data storage
- File Handling
- Datetime module
- Random module (for unique task IDs)
